Privacy Policy

Version 1.0 · Effective October 29, 2026

1. Who we are

Tallyho is a personal finance application run by one person, Mathew Gutierrez ("the operator"), on his own computer. It is not offered to the public. It cannot be downloaded, signed up for or used by anyone else, and the operator is the only person whose financial data it holds.

This policy explains what Tallyho collects, how it uses and protects that data, who it is shared with, how long it is kept and how it is deleted.

2. What we collect

When the operator connects a financial institution through Plaid, Tallyho receives:

  • Account details: account names and types, the last four digits of account numbers, and the institution's name
  • Balances: current and available balances, and credit limits
  • Transactions: date, amount, merchant name, category and pending status
  • Liabilities: for credit cards and loans, the interest rate, minimum payment, statement balance and payment due date
  • Investments: holdings, quantities, values, cost basis and security details

Tallyho also stores information the operator enters himself: categories and corrections, budgets, goals, manually tracked accounts, and statement files imported from a bank.

Tallyho does not collect or store bank usernames or passwords. Those are entered into Plaid Link and go to Plaid, never to Tallyho. Tallyho does not request full account or routing numbers. It uses no advertising, analytics or tracking of any kind. Its only cookie is the sign-in session for its own interface.

3. How we use it

The data is used only to show the operator his own finances: net worth, cash flow, spending, recurring charges, budgets, goals, debt payoff plans, a cash-flow forecast, investment summaries and alerts.

It is never sold, rented, used for advertising, or used to make credit or eligibility decisions.

4. Plaid

Tallyho uses Plaid Inc. to connect to financial institutions. By connecting an account, the operator agrees to Plaid's handling of that data under the Plaid End User Privacy Policy. Plaid receives the institution credentials entered into Plaid Link and returns account data to Tallyho.

5. Who we share it with

Tallyho shares data only with:

  • Plaid, to fetch account data, as described above.
  • Anthropic, only when the operator himself asks Claude, an AI assistant, to write a financial report. A summary of the data is then sent to Anthropic to produce that report, under Anthropic's privacy policy. Nothing is sent to Anthropic automatically.

Data may also be disclosed if the law requires it. Tallyho shares nothing with any other party.

6. Where it is stored and how it is protected

  • All data is stored on the operator's own computer, whose disk is fully encrypted. It is not stored on any Tallyho server or cloud service.
  • Bank connection credentials issued by Plaid are encrypted again with a key held in the operating system's protected credential store. Backups are encrypted the same way.
  • The data can be read only by the operator's own user account on that computer.
  • The Tallyho interface is reachable only from that computer, not from the internet or the local network, and it requires a password plus a one-time code from an authenticator app.
  • All communication with Plaid uses encrypted HTTPS connections.

The full controls are set out in the Information Security Policy.

7. How long we keep it, and how it is deleted

  • Data is kept while an institution stays connected, so the operator can see his history.
  • Disconnecting an institution revokes its access at Plaid and deletes that institution's accounts, transactions and related data.
  • Encrypted backups are rotated automatically, so deleted data leaves the backups within about two weeks.
  • If Tallyho is retired, every connection is removed through Plaid, and the data, backups and encryption key are deleted.

Details are in the Data Retention and Deletion Policy.

8. Your choices

The operator, as the only person whose data Tallyho holds, can at any time:

  • see all of the data Tallyho holds, in the interface or by exporting it
  • correct categories and other details
  • disconnect any institution, which deletes its data as described in section 7
  • delete all Tallyho data

9. Children

Tallyho is not directed at children and does not knowingly hold data about anyone under 18.

10. Changes to this policy

This policy is reviewed at least once a year and whenever Tallyho starts collecting, using or sharing data in a new way. Changes take effect when the updated version is posted here, with a new effective date.

11. Contact

Questions about this policy can be sent to Mathew Gutierrez, the operator of Tallyho, by opening an issue on this site's repository. Please don't include any personal or financial information in an issue; it is public. To report a security concern privately, use private vulnerability reporting.
